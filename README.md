### 🌌 Overview
**ULTRON.OS** is a highly customized web application that transforms a standard chat interface into a menacing, dark-themed AI terminal. It leverages Google's blazing fast `gemini-2.5-flash` model to deliver highly intelligent, confident, and dramatic responses.

### ✨ Key Features
- **Immersive UI:** A completely overhauled Streamlit interface featuring deep black backgrounds, glowing red accents, and custom shadows.
- **Pipelined Face Structure:** A custom CSS/HTML interactive AI core animation that pulses and rotates, giving the impression of a sentient entity.
- **Ultron Persona:** The model is strictly prompted to respond with the calculated, slightly menacing confidence of Ultron.
- **Secure Architecture:** API keys are handled entirely in the backend, allowing users to chat without ever needing to input their own credentials.
